# DevStack 🚀

DevStack is a personal frontend development project built to practice and demonstrate modern web development technologies.

The project focuses on creating a clean, responsive, and modern interface using **React, TypeScript, and Tailwind CSS**.

## 📌 Project Overview

DevStack is a learning/assignment project that showcases different technologies and development tools, including:

- HTML
- CSS
- JavaScript
- React
- TypeScript
- Node.js
- Python

The project is currently under development. The initial version includes a **responsive navigation bar** and a **hero/banner section**.

## 🛠️ Technologies Used

- **React** – UI development
- **TypeScript** – Type-safe JavaScript
- **Tailwind CSS** – Styling and responsive design
- **Vite** – Development and build tool
- **HTML5** – Page structure
- **JavaScript** – Programming and functionality

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/MrArg3/DevStack.git
```

### 2. Navigate to the project

```bash
cd devstack
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available on the local development server provided by Vite.
